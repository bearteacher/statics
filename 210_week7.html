函式：給樂句取名字

作曲時，我們會給主題取名字——主題 A、主題 B——之後在曲子裡反覆它、移調它、換樂器演奏它。程式也可以這樣做：把一段樂句用 define 包起來、取個名字，之後只要寫名字就能叫它出來。

這週只有 4 題，一節課 2 題。
每題三步：跑範例 → 仿照改 → 自己做。仿照改都在動「函式」；之前學過的語法放在函式裡當材料，想換就換。

函式的四個觀念

函式分兩步：先用 define 取名字（這時不會響），再寫名字把它叫出來（這時才會響）。

最簡單的函式
define :theme do       # 第一步：取名字叫 theme（不會響）
  play 60
  sleep 0.5
  play 64
  sleep 0.5
end
theme                  # 第二步：叫它出來（會響）
theme                  # 再叫一次
練習觀念像音樂裡的一句話
練習一define：取名字，再叫它出來給主題取名 A寫一次，叫很多次
練習二一個參數：從不同的音開始移調、模進叫的時候給一個起始音
練習三兩個參數：換音色和力度變奏、配器同一個主題，不同的演奏方式
練習四用函式排出曲式主題與變奏、A–A′–B–A叫哪個主題、叫幾次，就是曲式

三個規則

  1. 先 define，後呼叫　define 要寫在呼叫的上面；程式還不認識的名字會出現紅字。
  2. 名字前面有冒號，呼叫時沒有　取名寫 define :theme，呼叫只寫 theme。
  3. 總拍數＝呼叫次數 × 每次拍數　define 裡的 sleep 加起來是每次的拍數。

01　取名字，再叫它出來

這題練的觀念：用 define 給一段樂句取名字；寫名字就能把它叫出來，叫幾次就響幾次。

define 只是取名字，本身不會響；下面寫 theme 的地方，才是真正演奏。

① 範例（可直接跑）
define :theme do          # 給樂句取名字叫 theme
  play 60
  sleep 0.5
  play 64
  sleep 0.5
  play 67
  sleep 1
end                       # 每次 2 拍
use_synth :piano
theme                     # 叫它出來
theme                     # 再叫一次
# 2 次 × 2 拍 = 4 拍

② 仿照改（先預測，再 Run）

易　在最下面再多寫兩行 theme。預測：總共幾拍？
中　把最下面所有的 theme 都刪掉，只留 define。預測：按 Run 會聽到聲音嗎？
難　改回來後，把一行 theme 搬到整段程式的最上面（define 的上面）。預測：會發生什麼事？

函式裡的材料：play、sleep（第二週），use_synth（第三週）——想換就換，不是這題的重點。

③ 自己做

寫一個自己的 2～4 拍短動機，取一個名字，叫它 3 次。中間可以用 use_synth 換樂器。寫下呼叫算式。

自己核對

  • 總拍數＝呼叫次數 × 每次拍數；define 只是取名字，要呼叫才會響。

紀錄要寫：呼叫算式、我改了哪裡、聽起來差在哪、自己的版本，並貼上「自己做」的程式碼。

02　從不同的音開始

這題練的觀念：在名字後面加一個參數 |root|，叫它的時候給一個起始音——同一個主題就能移調、做模進。

theme 60 是從 60 開始，theme 65 是從 65 開始。主題的音程不變，只是整句換了位置。

① 範例（可直接跑）
define :theme do |root|   # root 是參數：叫的時候給起始音
  play root
  sleep 0.5
  play root + 4
  sleep 0.5
  play root + 7
  sleep 1
end
use_synth :piano
theme 60                  # 從 60 開始
theme 65                  # 從 65 開始
theme 67                  # 從 67 開始
# 3 次 × 2 拍 = 6 拍

② 仿照改（先預測，再 Run）

易　最後加一行 theme 72。預測：這次彈出哪三個音？
中　把三行呼叫換成迴圈：4.times do |i|、theme 60 + i * 2、end。預測：四次的起始音各是多少？
難　把 define 裡的 root + 4 改成 root + 3。預測：只有一次呼叫會變，還是每一次都會變？

函式裡的材料：play、sleep（第二週），root 的寫法（第四週），use_synth（第三週）——想換就換，不是這題的重點。

③ 自己做

把你練習一的動機加上參數 root，從三個不同的音開始，做出一段模進。寫下每次的起始音。

自己核對

  • 每次呼叫的起始音＋音程，就是實際彈出的音；改 define 一處，每次呼叫都跟著變。

紀錄要寫：呼叫算式、我改了哪裡、聽起來差在哪、自己的版本，並貼上「自己做」的程式碼。

03　換音色和力度

這題練的觀念：參數可以不只一個：給起始音，也給樂器——同一個主題，做出不同配器的變奏。

叫的時候，值要照順序給、用逗號隔開：theme 60, :piano 的 60 給 root，:piano 給 inst。

① 範例（可直接跑）
define :theme do |root, inst|   # 兩個參數：起始音、樂器
  use_synth inst
  play root
  sleep 0.5
  play root + 4
  sleep 0.5
  play root + 7
  sleep 1
end
theme 60, :piano
theme 60, :pluck
theme 67, :pretty_bell
# 3 次 × 2 拍 = 6 拍

② 仿照改（先預測，再 Run）

易　把第二行呼叫改成 theme 55, :prophet。預測：這一次有哪兩個地方變了？
中　加第三個參數 vol：改成 define :theme do |root, inst, vol|，每個 play 後面加 , amp: vol，三行呼叫都補上第三個值（例如 0.3、0.6、1）。預測：哪一次最大聲？
難　故意少給一個值：把其中一行改成 theme 60, :piano。預測：會發生什麼事？（看完記得補回來）

函式裡的材料：use_synth、amp（第三週）——想換就換，不是這題的重點。

③ 自己做

同一個主題，做出至少三次變奏：一次換起始音、一次換樂器、一次換力度。寫下每次呼叫給了哪些值。

自己核對

  • 呼叫時給的值，數量和順序要和 define 的參數一樣。

紀錄要寫：呼叫算式、我改了哪裡、聽起來差在哪、自己的版本，並貼上「自己做」的程式碼。

04　用函式排出曲式

這題練的觀念：定義兩個主題，再用呼叫排出 A–A′–B–A：叫哪個主題、從哪個音開始、叫幾次，就是曲式。

上面先定義主題，下面只負責「排順序」，整首的結構一眼就看得出來。這段程式會自己結束，錄音時按 Rec → Run → 結束後再按 Rec。

① 範例（可直接跑）
use_bpm 96
define :theme_a do |root|   # 主題 A：上行，2 拍
  play_pattern_timed [root, root + 4, root + 7], [0.5, 0.5, 1]
end
define :theme_b do |root|   # 主題 B：下行，2 拍
  play_pattern_timed [root + 12, root + 7, root + 4, root], 0.5
end
use_synth :piano
# A：主題（2 次 × 2 拍 = 4 拍）
2.times do
  theme_a 60
end
# A′：移調變奏（4 拍）
theme_a 65
theme_a 67
# B：對比，換樂器（4 拍）
use_synth :pluck
2.times do
  theme_b 60
end
# A 回來（4 拍）
use_synth :piano
2.times do
  theme_a 60
end
# 4 ＋ 4 ＋ 4 ＋ 4 ＝ 16 拍

② 仿照改（先預測，再 Run）

易　把 A′ 的 65、67 改成 62、64。預測：總拍數會變嗎？
中　在 use_synth :piano 下面、A 段前面，加一個前奏：叫一次 theme_b 72。預測：總拍數變多少？
難　讓 B 段有鼓伴奏：在 B 段的 2.times 前面加 in_thread do、4.times do、sample :bd_haus、sleep 1、end、end。預測：鼓打幾拍？會不會超過 B 段？

函式裡的材料：use_bpm、註解（第四週），use_synth（第三週），x.times（第五週），play_pattern_timed（第二週）——想換就換，不是這題的重點。

③ 自己做

定義至少兩個主題（都要有參數），排出 A–A′–B–A 或你自己的曲式，總長 16～32 拍。每段上面用註解寫拍數。完成後按 Rec → Run → 結束後再按 Rec，存成 .wav。

自己核對

  • 每段的「呼叫次數 × 每次拍數」加起來，是不是你要的總拍數？

紀錄要寫：呼叫算式、我改了哪裡、聽起來差在哪、自己的版本，並貼上「自己做」的程式碼。
