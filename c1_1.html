整數除法：截斷不是四捨五入

核心規則

int 除以 int，結果仍是 int，小數點後直接丟棄

int a = 7, b = 3;
printf("%d\n", a / b);    // 輸出 2，不是 2.33
printf("%d\n", 10 / 3);   // 輸出 3，不是 3.33
printf("%d\n", -7 / 3);   // 輸出 -2（向零截斷）

int a = 7, b = 3;
printf("%d\n", a / b);    // 輸出 2，不是 2.33
printf("%d\n", 10 / 3);   // 輸出 3，不是 3.33
printf("%d\n", -7 / 3);   // 輸出 -2（向零截斷）
🚨 常見錯誤

把 7/3 算成 2.33！

整數除法直接丟掉小數，不會四捨五入。

型別提升：遇到浮點數就升級

規則

運算式中只要有一個 float 或 double，整個結果就變成浮點數

int a = 7, b = 3;

float w = a / 2 / b * 1.0;   // 先整數：7/2=3, 3/3=1, 1*1.0=1.0
float x = a / b / 2.0;        // 先整數：7/3=2, 2/2.0=1.0
float y = a / 2 / b;          // 全整數：7/2=3, 3/3=1 → 存為 1.0
float z = 1.0 * a / 2 / b;   // 一開始就是浮點：7.0/2/3 ≈ 1.167

int a = 7, b = 3;

float w = a / 2 / b * 1.0;   // 先整數：7/2=3, 3/3=1, 1*1.0=1.0
float x = a / b / 2.0;        // 先整數：7/3=2, 2/2.0=1.0
float y = a / 2 / b;          // 全整數：7/2=3, 3/3=1 → 存為 1.0
float z = 1.0 * a / 2 / b;   // 一開始就是浮點：7.0/2/3 ≈ 1.167
⚠️ 運算順序很重要

乘除由左至右執行。1.0 * a 最先算，後面都是浮點。

🔖 快速判斷技巧

從左掃到右，第一次遇到浮點數，那個位置之後都是浮點運算。

4 / 10

型別提升：追蹤練習

逐步拆解 z 的計算

float z = 1.0 * a / 2 / b;   // a=7, b=3

float z = 1.0 * a / 2 / b;   // a=7, b=3
步驟 運算 型別 結果
1 1.0 * a double * int → double 7.0
2 7.0 / 2 double / int → double 3.5
3 3.5 / b double / int → double 1.1666...
✅ 結論

w、x、y 都是 1.0；z 是 1.1666...

z 是四個式子中的「異類」

前置 vs 後置遞增

最容易混淆的考點

寫法 執行順序 printf("%d", ?) 的輸出
++i 先加 1，再取值印出 印出加完後的值
i++ 先取值印出，再加 1 印出加完前的值 
int i = 0;
printf("%d ", ++i);   // i 先變 1，印 1；目前 i=1
printf("%d ", i++);   // 先印 1，再變 2；目前 i=2
printf("%d ", i);     // 直接印目前的 i=2

int i = 0;
printf("%d ", ++i);   // i 先變 1，印 1；目前 i=1
printf("%d ", i++);   // 先印 1，再變 2；目前 i=2
printf("%d ", i);     // 直接印目前的 i=2

輸出：1 1 2

🚨 後置遞增常見誤解

i++ 不是「先加再用」，而是「先用再加」！

6 / 10

前置 vs 後置遞增：完整追蹤

範例：推出輸出序列

int i = 0;
printf("%d ", ++i);   // (A)
printf("%d ", ++i);   // (B)
printf("%d ", i);     // 直接印 i
printf("%d ", ++i);   // (C)
printf("%d ", i++);   // (D)

int i = 0;
printf("%d ", ++i);   // (A)
printf("%d ", ++i);   // (B)
printf("%d ", i);     // 直接印 i
printf("%d ", ++i);   // (C)
printf("%d ", i++);   // (D)
位置 操作 i 的值 印出
(A) ++i 先加 0→1 1
(B) ++i 先加 1→2 2
直接印 無 2 2
(C) ++i 先加 2→3 3
(D) i++ 先印後加 3→4 3

輸出：1 2 2 3 3

前置 vs 後置遞增：反推練習

已知輸出，填入正確運算子

int i = 0;
printf("%d ", __(1)__);   // 輸出 1
printf("%d ", __(2)__);   // 輸出 2
printf("%d ", i);         // 輸出 2
printf("%d ", __(3)__);   // 輸出 3
printf("%d ", __(4)__);   // 輸出 3

int i = 0;
printf("%d ", __(1)__);   // 輸出 1
printf("%d ", __(2)__);   // 輸出 2
printf("%d ", i);         // 輸出 2
printf("%d ", __(3)__);   // 輸出 3
printf("%d ", __(4)__);   // 輸出 3
🔖 解題策略

從輸出序列推回去：

  • 輸出與當前 i 值相同 → 用 i++（先印再加）
  • 輸出比當前 i 值多 1 → 用 ++i（先加再印）
✅ 答案

(1) ++i　(2) ++i　(3) ++i　(4) i++

8 / 10

本節觀念整理

✅ 三大核心規則
  1. 整數除法截斷：int/int = int，小數點後直接捨去，不四捨五入
  2. 型別提升：左到右遇到第一個浮點數後，後續全為浮點運算
  3. 前置後置遞增：++i 先加後用；i++ 先用後加
⚠️ 最常見的 APCS 陷阱
  • 看到 7/3 直覺算成 2.33 → 應為 2
  • 看到 i++ 以為先加 → 其實是先用再加
  • 忽略運算式從左到右的浮點「感染」時機
