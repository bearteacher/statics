a003・兩光法師占卜術
這一份講義的目標只有一個：你自己把 Python 程式送進 ZeroJudge，看到綠色的 AC。
我們不從完整答案開始，而是把題目拆成 4 個很小的任務。
讀入日期→套公式→判斷 0/1/2→輸出運勢
扉頁
讀題
先看懂任務

這題到底要電腦做什麼？

輸入

一行有兩個整數：

月份 M、日期 D

1 2

輸出

根據算出的 S：

0 → 普通
1 → 吉
2 → 大吉

S = (M × 2 + D) % 3
  • 這題不是在考曆法，而是在考 輸入、算術運算、餘數、條件判斷。
  • 題目給的範例 1 1 會輸出「普通」；1 2 會輸出「吉」。
  • 先不要想整份程式，照著「輸入 → 計算 → 判斷 → 輸出」分四步做。
真正的解題能力：把文字題目翻譯成程式的四個動作。
第一頁
輸入
第一關

一行讀進兩個整數

輸入資料stdin
1 2　← 月份和日期中間用空白隔開
Python：把一行中的兩個數字分別放進 m、d
m, d = map(int, input().split())
片段做什麼
input()讀入整行文字，例如 "1 2"
.split()用空白切開 → ["1", "2"]
map(int, ...)把文字轉成整數 → 1, 2
m, d = ...m 得到 1，d 得到 2
Online Judge 不要寫 input("請輸入月份：") —— 多印出的提示文字會讓答案錯掉
第二頁
餘數
第二關

% 是「除完以後的餘數」

7 % 3

7 ÷ 3 = 2 …… 1

所以 7 % 3 = 1

8 % 3

8 ÷ 3 = 2 …… 2

所以 8 % 3 = 2

s = (m * 2 + d) % 3
若輸入 1 2：先算 1*2+2 = 4
再算 4 % 3 = 1
所以 s = 1，等一下應該輸出「吉」
S = 1 → 吉
第三頁
判斷
第三關

三種結果，用 if / elif / else

s == 0？→普通／s == 1？→吉／其他→大吉
條件判斷骨架
if s == 0:
    print("普通")
elif s == 1:
    print("吉")
else:
    print("大吉")
  • == 是比較是否相等；= 是把值存進變數。
  • elif 是「前一個不成立，再問另一個條件」。
  • 因為除以 3 的餘數只可能是 0、1、2，所以最後的 else 一定就是 2。
第四頁
手算
先不用電腦

你能預測程式會印什麼嗎？

輸入m×2+d% 3應輸出
1 11×2+1 = 30普通
1 21×2+2 = 41吉
2 12×2+1 = 52大吉
快速檢查：輸入 9 15，程式應該輸出什麼？
(9×2+15)%3 = 33%3 = 0，所以輸出 普通。
如果你能手算出答案，遇到 WA 時就能分辨：是公式錯、判斷錯，還是輸出格式錯。
第五頁
組合
第四關

現在把四塊拼成完整程式

① input→② 公式→③ if→④ print
先自己寫 3～5 分鐘。真的卡住再按下面按鈕。
可直接提交 ZeroJudge 的版本
m, d = map(int, input().split())
s = (m * 2 + d) % 3

if s == 0:
    print("普通")
elif s == 1:
    print("吉")
else:
    print("大吉")
這題的核心不是背答案，而是學會一個可重複使用的流程：讀入 → 計算 → 分支 → 輸出。

第九頁
評分
送出之後

AC、WA、CE、RE 是什麼？

狀態意思第一個檢查動作
ACAccepted，通過恭喜，記錄你學到的寫法
WAWrong Answer，答案不對手算一組 → 比較程式輸出
CECompile Error，語法/編譯錯誤看錯誤行號、冒號、縮排、括號
RERuntime Error，執行時出錯檢查 input / 轉型 / 變數
TLETime Limit Exceeded，太慢這題若正常寫幾乎不會發生
ZeroJudge 首頁也會解釋各種評分狀態。初學時最常遇到的通常是 WA 與 CE。
第十頁
除錯
最常見錯誤

這 5 個錯誤，會讓你明明「看起來差不多」卻過不了

#錯誤寫法 / 現象正確觀念
1input("請輸入：")Judge 不需要提示文字，用 input()
2if s = 0:比較要用 ==
3if / elif 後忘記 :Python 條件列最後要冒號
4print 沒有縮排if 裡面的敘述要縮排
5輸出 "吉!" 或 "結果是吉"照題目要求，只印「普通 / 吉 / 大吉」
除錯練習：
m, d = input().split()
s = (m * 2 + d) % 3

split() 得到的是文字；要先轉成整數。可改成：

m, d = map(int, input().split())
第十一頁
完成
總結

看到 AC 之後，你真正學會的是這 5 件事

  • 讀題：找出輸入、輸出、公式與條件。
  • 輸入：用 map(int, input().split()) 讀同一行的兩個整數。
  • 運算：用 % 取得餘數。
  • 判斷：用 if / elif / else 處理不同情況。
  • Online Judge：程式不能多印提示文字，提交後要看 AC / WA / CE 等評分結果。
