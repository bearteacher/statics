布林運算：三個運算子

基本規則

運算子 中文 成立條件 範例（a=5, b=3）
&& 且（AND） 兩者都為 true a>3 && b>1 → true
\|\| 或（OR） 至少一者為 true a>6 \|\| b>1 → true
! 非（NOT） 取反 !(a>3) → false 
int a = 5, b = 3;
printf("%d\n", a > 3 && b > 1);   // 1（true）
printf("%d\n", a > 6 || b > 1);   // 1（true）
printf("%d\n", !(a > 3));          // 0（false）

int a = 5, b = 3;
printf("%d\n", a > 3 && b > 1);   // 1（true）
printf("%d\n", a > 6 || b > 1);   // 1（true）
printf("%d\n", !(a > 3));          // 0（false）

短路求值（Short-circuit）

遇到確定答案就停下來

⚠️ 短路規則
  • &&：左側為 false → 右側不執行（反正結果是 false）
  • ||：左側為 true → 右側不執行（反正結果是 true）
int i = 0;
// && 短路：左側 false 就停，i++ 不執行
if (0 && (i++)) { }
printf("%d\n", i);   // 輸出 0（i++ 沒被執行）

// || 短路：左側 true 就停，i++ 不執行
if (1 || (i++)) { }
printf("%d\n", i);   // 輸出 0（i++ 仍沒被執行）

int i = 0;
// && 短路：左側 false 就停，i++ 不執行
if (0 && (i++)) { }
printf("%d\n", i);   // 輸出 0（i++ 沒被執行）

// || 短路：左側 true 就停，i++ 不執行
if (1 || (i++)) { }
printf("%d\n", i);   // 輸出 0（i++ 仍沒被執行）
🔖 APCS 考法

在右側放有副作用的運算（如 i++），問最後 i 的值。 短路 → i 不變；不短路 → i 加 1。

if-else if-else：只走一條路

核心特性

一旦某個條件成立，執行完對應的區塊後，後面所有 else if 和 else 全部跳過。

int score = 85;

if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {
    printf("B\n");        // ← score=85：score>=80 成立，印 B，後面跳過
} else if (score >= 70) {
    printf("C\n");        // 不會執行
} else {
    printf("F\n");        // 不會執行
}

⚠️ 邊界值陷阱

APCS 最愛在邊界值（90、80、70）附近出題。 score = 80 時，>= 80 成立，輸出 B（不是 C！）

無括號縮排陷阱

else 永遠配對最近的 if

int x = 4, a = 0;

if (x >= 2)         // ← 條件 1
    if (x < 6)      // ← 條件 2
        a = 1;
    else             // ← 這個 else 配對「條件 2」，不是「條件 1」！
        a = 2;
else
    a = 3;

    else             // ← 這個 else 配對「條件 2」，不是「條件 1」！

else

🚨 視覺陷阱分析

縮排讓人以為 else 配對 if(x>=2)，但 C/C++ 的規則是： else 永遠配對最近的、尚未配對的 if

→ 中間那個 else 配對的是 if(x < 6)

x 的值 進入哪個分支 a 的結果
x = 4 條件1成立→條件2成立→ a=1 1
x = 7 條件1成立→條件2不成立→中間else→ a=2 2
x = 1 條件1不成立→最外層else→ a=3 3

switch：無 break 的下墜

fall-through 是 APCS 超高頻考點

int a = 2;
switch(a) {
    case 1+1:           // 2 == 2，進入！
        printf("A");    // 印 A，沒有 break，繼續往下…
    case 1+2:           // 不管條件是否符合，直接執行
        printf("B");
        break;          // 離開 switch
    default:
        printf("??");
}
// 輸出：AB

switch(a) {
    case 1+1:           // 2 == 2，進入！
        printf("A");    // 印 A，沒有 break，繼續往下…
    case 1+2:           // 不管條件是否符合，直接執行
        printf("B");
        break;          // 離開 switch
    default:
        printf("??");
}
// 輸出：AB
🚨 fall-through 機制

進入某個 case 後，如果沒有 break，會繼續執行下一個 case 的程式碼， 不管下一個 case 的條件是否符合。

switch vs if：精確比對 vs 範圍比較

兩種寫法的本質差異

// switch 版（精確比對整數）
switch(n) {
    case 90: printf("A"); break;
    case 80: printf("B"); break;
    case 70: printf("C"); break;
    default: printf("D");
}

// if 版（範圍比較）
if      (n >= 90) printf("A");
else if (n >= 80) printf("B");
else if (n >= 70) printf("C");
else              printf("D");

// switch 版（精確比對整數）
switch(n) {
    case 90: printf("A"); break;
    case 80: printf("B"); break;
    case 70: printf("C"); break;
    default: printf("D");
}

// if 版（範圍比較）
if      (n >= 90) printf("A");
else if (n >= 80) printf("B");
else if (n >= 70) printf("C");
else              printf("D");
⚠️ 差異在哪？

switch 的 case 90 只有在 n 精確等於 90 時才成立。

n = 85 時：

  • switch 版 → case 85 不存在 → 輸出 D
  • if 版 → n >= 80 成立 → 輸出 B

🔖 解題步驟
  1. switch 只有 case 90, 80, 70 三個精確值
  2. 其他值都走 default → 輸出 D
  3. if 版：80 <= n < 90 的值輸出 B（如 n=85）
  4. 所以：任何在範圍內但不是 case 整數的值都會讓兩者輸出不同

本節觀念整理

✅ 四大核心規則
  1. 短路求值：&& 左側 false 或 || 左側 true → 右側不執行
  2. if-else if：第一個成立的條件執行完後，後面全部跳過
  3. else 就近原則：else 配對最近的未配對 if，縮排不算數
  4. switch fall-through：沒有 break → 繼續執行下一個 case
⚠️ 最常見 APCS 陷阱
  • 巢狀 if 的 else 配對方向
  • switch 無 break 的連鎖輸出
  • switch case 只做整數精確比對（不是範圍）
