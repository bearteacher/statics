雙函式互呼：為什麼難？

兩個函式互相呼叫，輸出散在各處

void f1(int i) {
    if (i < 10) {
        f2(i - 2);          // 先呼叫 f2（輸出在裡面）
        printf("%d ", i);   // 回來後才印（後序）
    }
}
void f2(int i) {
    if (i > 0) {
        printf("%d ", i);   // 先印（前序）
        f1(i - 1);          // 再呼叫 f1（輸出在裡面）
    }
}

void f1(int i) {
    if (i < 10) {
        f2(i - 2);          // 先呼叫 f2（輸出在裡面）
        printf("%d ", i);   // 回來後才印（後序）
    }
}
void f2(int i) {
    if (i > 0) {
        printf("%d ", i);   // 先印（前序）
        f1(i - 1);          // 再呼叫 f1（輸出在裡面）
    }
}
⚠️ 為什麼直覺容易出錯？
  • f1 的 printf 在呼叫後 → 要等 f2 的整棵樹跑完才印
  • f2 的 printf 在呼叫前 → 進入就立刻印
  • 兩者交錯 → 必須畫呼叫樹，不能憑直覺

🔖 關鍵規律

f2 進入時先印（越深的 f2 越後印，但比 f1 早）

f1 回收時才印（越深的 f1 越先印，因為越先回收）

輸出行數計算

不需要完整展開，找規律

void g(int n) {
    if (n <= 0) return;
    printf("%d\n", n);
    g(n - 3);
    g(n - 2);
}
// g(6) 總共印出幾個數字？

void g(int n) {
    if (n <= 0) return;
    printf("%d\n", n);
    g(n - 3);
    g(n - 2);
}
// g(6) 總共印出幾個數字？
🔖 解題策略

展開前幾層，找「哪些呼叫有效（n>0）」：

g(6) → 印6；呼叫 g(3), g(4)
  g(3) → 印3；呼叫 g(0), g(1)
    g(0) → n<=0，結束
    g(1) → 印1；呼叫 g(-2), g(-1) → 都結束
  g(4) → 印4；呼叫 g(1), g(2)
    g(1) → 印1；呼叫 g(-2), g(-1) → 都結束
    g(2) → 印2；呼叫 g(-1), g(0) → 都結束

g(6) → 印6；呼叫 g(3), g(4)
  g(3) → 印3；呼叫 g(0), g(1)
    g(0) → n<=0，結束
    g(1) → 印1；呼叫 g(-2), g(-1) → 都結束
  g(4) → 印4；呼叫 g(1), g(2)
    g(1) → 印1；呼叫 g(-2), g(-1) → 都結束
    g(2) → 印2；呼叫 g(-1), g(0) → 都結束

印出的值：6, 3, 1, 4, 1, 2 → 共 6 個

已知回傳值填挖空

反推條件邊界

int f(int a) {
    if (a < (?)) return a;        // ← ? 填幾？
    return f(a - 3) + f(a - 5);
}
// 已知：f(7) = 7

int f(int a) {
    if (a < (?)) return a;        // ← ? 填幾？
    return f(a - 3) + f(a - 5);
}
// 已知：f(7) = 7
🔖 解題步驟

已知 f(7)=7，代入： f(7) = f(4) + f(2)

如果 a < ? 讓 f(2) 直接回傳 2： → 需要 2 < ?

如果 a < ? 讓 f(4) 也要繼續遞迴： → 需要 4 >= ?，即 ? <= 4

結合：2 < ? <= 4 → ? = 3 或 ? = 4

驗算 ? = 3：

  • f(2) = 2（2<3 成立）
  • f(4) = f(1)+f(-1) = 1+(-1) = 0（但 -1 < 3 → f(-1)=-1）
  • f(7) = 0+2 = 2 ≠ 7 ✗

驗算 ? = 4：

  • f(2)=2, f(4)=4（因為 4≥4 → 繼續？不對，4<4 不成立）
  • 重來：4<4 不成立 → f(4) = f(1)+f(-1) = 1+(-1) = 0
  • 還是 0+2=2 ✗

已知回傳值填挖空（續）

更直觀的方法：逆向思考

✅ 正確解法

若 f(7) 要等於 7，最簡單的情況是 a < 8 直接 return a：

驗算 ? = 8：

  • f(7) = 7（7 < 8 成立，直接回傳 7）✓
  • f(2) = 2（2 < 8 成立）✓
  • f(4) = 4（4 < 8 成立）✓

若 ? = 5：

  • f(7)：7 < 5 不成立 → f(7) = f(4)+f(2) = 4+2 = 6 ≠ 7 ✗

→ 答案：? = 8（或更大的值讓 base case 覆蓋到 7）

本節觀念整理

✅ 雙函式互呼解題流程
  1. 畫呼叫樹：以縮排表示深度，標記每個呼叫
  2. 標記輸出位置：printf 在呼叫前 → 進入時印；在呼叫後 → 回收時印
  3. 由上往下讀：進入順序決定「前序」輸出；回收順序決定「後序」輸出
  4. 收集所有輸出：按照呼叫樹的時間軸排列
⚠️ 兩個最容易犯的錯
  1. 忘記 f1 的 printf 是後序（回收時才印），以為進入時就印
  2. 呼叫樹展開不完整，漏掉某一層或某一個分支
