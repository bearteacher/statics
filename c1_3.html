for 迴圈的三個部分

拆解迴圈結構

for (初始值; 條件; 更新) {
    // 迴圈本體
}

for (初始值; 條件; 更新) {
    // 迴圈本體
}

for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// 輸出：1 2 3 4 5

for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// 輸出：1 2 3 4 5
部分 說明 本例
初始值 執行一次，最先執行 i = 1
條件 每次迴圈前檢查 i <= 5
更新 每次迴圈結束後執行 i++

非標準步長：最容易算錯的地方

步長不是 1 的情況

int s = 0;
for (int i = 1; i <= 6; i = i + 2) {
    s = s + i;
}
printf("%d\n", s);

int s = 0;
for (int i = 1; i <= 6; i = i + 2) {
    s = s + i;
}
printf("%d\n", s);
🚨 常見錯誤

直覺認為「1 到 6 跑 6 次」→ 算出 s = 21（1+2+3+4+5+6）

步長是 +2，不是 +1！

第幾次 i 的值 條件 i<=6 執行 s+=i
1 1 ✅ s=0+1=1
2 3 ✅ s=1+3=4
3 5 ✅ s=4+5=9
4 7 ❌ 停止 —

輸出：9

邊界條件：< 與 <= 的一字之差

差一次的邊界陷阱

// 版本 A：< 5
for (int i = 0; i < 5; i++) { printf("%d ", i); }
// 輸出：0 1 2 3 4（共 5 次）

// 版本 B：<= 5
for (int i = 0; i <= 5; i++) { printf("%d ", i); }
// 輸出：0 1 2 3 4 5（共 6 次）

// 版本 A：< 5
for (int i = 0; i < 5; i++) { printf("%d ", i); }
// 輸出：0 1 2 3 4（共 5 次）

// 版本 B：<= 5
for (int i = 0; i <= 5; i++) { printf("%d ", i); }
// 輸出：0 1 2 3 4 5（共 6 次）
⚠️ 邊界陷阱口訣

< n：執行 n 次（從 0 到 n-1）

<= n：執行 n+1 次（從 0 到 n）

🔖 APCS 考法

題目會把 < 換成 <=（或反過來），讓你少算或多算一次。 解題前先確認是哪個符號！

while 迴圈：多變數同步追蹤

不能只追蹤一個變數

int x = 5, y = 0;
while (x > 0) {
    y = y + x;
    x = x - 2;
}
printf("%d %d\n", x, y);

int x = 5, y = 0;
while (x > 0) {
    y = y + x;
    x = x - 2;
}
printf("%d %d\n", x, y);
🔖 解題策略：畫追蹤表格

每一輪迴圈，同時更新所有變數。

輪次 進入條件 x>0 y = y+x x = x-2 離開時
1 5>0 ✅ y=0+5=5 x=5-2=3 —
2 3>0 ✅ y=5+3=8 x=3-2=1 —
3 1>0 ✅ y=8+1=9 x=1-2=-1 —
4 -1>0 ❌ — — 停止

輸出：-1 9

while 迴圈：負值終止要注意

迴圈結束時變數已經超出範圍

🚨 常見錯誤

追蹤到 x = 1 就以為結束，忘記還要執行一次 x = x - 2。

x = 1 時條件成立，還要執行迴圈本體！ 执行完後 x = -1，然後才判斷條件不成立，離開迴圈。

// 離開迴圈後的 x 值：
// x = 1 → 執行 x = x - 2 → x = -1 → 條件 x > 0 不成立 → 停止
// 所以輸出的 x 是 -1，不是 1！

// 離開迴圈後的 x 值：
// x = 1 → 執行 x = x - 2 → x = -1 → 條件 x > 0 不成立 → 停止
// 所以輸出的 x 是 -1，不是 1！

巢狀迴圈：圖形輸出

雙層迴圈印三角形

for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) {   // 內層上限是 i
        printf("* ");
    }
    printf("\n");
}

for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) {   // 內層上限是 i
        printf("* ");
    }
    printf("\n");
}
i 值 內層 j 範圍 印出
1 j=1 to 1 *
2 j=1 to 2 * *
3 j=1 to 3 * * *
4 j=1 to 4 * * * *

輸出：左對齊的正三角形（左下直角）

        printf("* ");
    }
    printf("\n");
}
🔖 解題技巧

觀察每一列星號數量與 i 的關係：

  • i=1：4個 → n-i+1 = 4
  • i=2：3個 → n-i+1 = 3
  • i=3：2個 → n-i+1 = 2
  • i=4：1個 → n-i+1 = 1
✅ 答案

j <= n - i + 1（也可寫成 j <= 5 - i，當 n=4）

本節觀念整理

✅ 四大核心技巧
  1. 步長非 1 → 列表格，逐次計算 i 的值
  2. 邊界 < vs <= → <n 跑 n 次，<=n 跑 n+1 次
  3. 多變數 while → 每一輪所有變數一起更新，注意負值終止
  4. 巢狀迴圈圖形 → 觀察星號數與 i 的對應關係推出條件
⚠️ 解題前的必做動作
  1. 確認步長（i++？i+=2？i*=2？）
  2. 確認邊界符號（<？<=？）
  3. 如果有多個變數，畫追蹤表格
