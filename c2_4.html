類型一：特定敘述執行次數

問的不是迴圈跑幾次，而是某行被執行幾次

int x = 0;
for (int i = 1; i <= 10; i++)
    for (int j = 1; j <= 10; j++)
        if (i + j == 11) x++;
printf("%d\n", x);

int x = 0;
for (int i = 1; i <= 10; i++)
    for (int j = 1; j <= 10; j++)
        if (i + j == 11) x++;
printf("%d\n", x);
🔖 解題步驟
  1. 外層迴圈 i 跑 1~10，共 10 次
  2. 內層迴圈 j 跑 1~10，共 10 次
  3. 問：i + j == 11 有幾組 (i,j) 滿足？
    • (1,10), (2,9), (3,8), (4,7), (5,6), (6,5), (7,4), (8,3), (9,2), (10,1)
    • 共 10 組
  4. x++ 執行 10 次 → 輸出 10

類型一：實戰練習

不同的條件，不同的觸發次數

int x = 0;
for (int i = 1; i <= 5; i++)
    for (int j = 1; j <= i; j++)   // 內層跑到 i，不是固定值
        if ((i + j) % 2 == 0) x++;

int x = 0;
for (int i = 1; i <= 5; i++)
    for (int j = 1; j <= i; j++)   // 內層跑到 i，不是固定值
        if ((i + j) % 2 == 0) x++;
i j 範圍 滿足 (i+j)%2==0 的 j 次數
1 1 j=1: 2%2=0 ✓ 1
2 1~2 j=2: 4%2=0 ✓ 1
3 1~3 j=1: 4%2=0 ✓, j=3: 6%2=0 ✓ 2
4 1~4 j=2,4 ✓ 2
5 1~5 j=1,3,5 ✓ 3

x++ 共執行 1+1+2+2+3 = 9 次

類型二：變步長迴圈

步長本身在改變，不是固定值

int j = 0;
for (int i = 0; i < 128; i = i + j + 1)
    j = i + 1;
printf("%d\n", j);

int j = 0;
for (int i = 0; i < 128; i = i + j + 1)
    j = i + 1;
printf("%d\n", j);
🔖 解題步驟：列出每次執行後的 i 值

不能套公式，要手算前幾次找規律：

輪次 執行前 i 執行 j=i+1 執行後 i=i+j+1 條件 i<128
1 0 j=1 i=0+1+1=2 ✅
2 2 j=3 i=2+3+1=6 ✅
3 6 j=7 i=6+7+1=14 ✅
4 14 j=15 i=14+15+1=30 ✅
5 30 j=31 i=30+31+1=62 ✅
6 62 j=63 i=62+63+1=126 ✅
7 126 j=127 i=126+127+1=254 ❌ 停止

輸出 j = 127（共執行 7 次）

類型三：三層巢狀迴圈公式

不要逐一計算，套公式！

int x = -100;
for (int i=1; i<=8; i++)
    for (int j=1; j<=i; j++)
        for (int k=1; k<=j; k++)
            x += 1;
printf("%d\n", x);

int x = -100;
for (int i=1; i<=8; i++)
    for (int j=1; j<=i; j++)
        for (int k=1; k<=j; k++)
            x += 1;
printf("%d\n", x);
✅ 三層巢狀公式

$$\sum_{i=1}^{n}\sum_{j=1}^{i}\sum_{k=1}^{j} 1 = \frac{n(n+1)(n+2)}{6}$$

n=8 代入：$\frac{8 \times 9 \times 10}{6} = \frac{720}{6} = 120$

x = -100 + 120 = 20

🔖 雙層巢狀公式

$$\sum_{i=1}^{n}\sum_{j=1}^{i} 1 = \frac{n(n+1)}{2}$$

類型三：公式對應表

快速識別適用哪個公式

迴圈結構 公式 n=5 時
for i; for j<=i $\frac{n(n+1)}{2}$ 15
for i; for j<=i; for k<=j $\frac{n(n+1)(n+2)}{6}$ 35
for i; for j=1 to n（固定） $n^2$ 25
⚠️ 注意內層範圍

內層是 j <= i（依賴外層）→ 用公式

內層是 j <= 5（固定值）→ 直接乘以 n

類型四：不可能的輸出

分析 while 結束後的值域

int f(int n) {
    if (n > 17) n += 5;
    while (n >= 23) n -= 6;  // ← 這個 while 結束後，n 的值域是？
    if (n > 17) n += 2;
    return n;
}

int f(int n) {
    if (n > 17) n += 5;
    while (n >= 23) n -= 6;  // ← 這個 while 結束後，n 的值域是？
    if (n > 17) n += 2;
    return n;
}
🔖 解題步驟

步驟 1：找 while 結束後 n 的所有可能值

while (n >= 23) n -= 6：離開時 n < 23，而且每次只減 6，所以：

n 結束時 ∈ {17, 18, 19, 20, 21, 22}（小於 23，且差距為 6 的倍數）

步驟 2：代入最後一個 if

  • n = 17：17 > 17 不成立 → 回傳 17
  • n = 18~22：n > 17 成立 → n+2 → 回傳 20, 21, 22, 23, 24

可能回傳值：17, 20, 21, 22, 23, 24 不可能回傳：19 ← 這就是答案

類型四：值域分析技巧

為什麼 n 一定在 {17,18,19,20,21,22}？

while (n >= 23) n -= 6

while (n >= 23) n -= 6

離開條件：n < 23

每次減 6，所以 n 的值域是一組以 6 為間隔的數字。

考慮從各種初始值進入的情況：

  • n=23 → 減一次 → n=17
  • n=24 → 減一次 → n=18
  • n=25 → 減一次 → n=19
  • n=29 → 減一次 → n=23 → 再減 → n=17
  • ⋮

結論：離開 while 後 n ∈ {17, 18, 19, 20, 21, 22}（恰好一個完整的週期）

本節觀念整理

✅ 四種題型與解法
  1. 特定敘述計次：分析條件觸發頻率，列出所有滿足的 (i,j) 組合
  2. 變步長迴圈：手動列表，每次計算新的步長，找規律
  3. 三層巢狀：直接套公式 $\frac{n(n+1)(n+2)}{6}$，不要逐一計算
  4. 不可能輸出：分析 while 後的值域，再代入後續 if，排除不可能
⚠️ 考場時間管理

這類題目計算量大，建議：

  • 特定敘述計次：2 分鐘內
  • 變步長：列 6~8 次，找到規律就停
  • 三層巢狀：直接套公式，< 30 秒
  • 不可能輸出：先分析值域，再逐一代入
