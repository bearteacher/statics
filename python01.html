第五頁
其六・輸出
補充

print() 的三種用法

① 逗號隔開，中間自動空一格
print("Hello", "python")
Hello python
② 直接印出運算結果
print(1 + 2)
3
③ 字串照印，運算式先算再印
print("1+2=", 1+2)
1+2= 3
  • 逗號會自動多印一個空格：所以是「Hello python」不是「Hellopython」。
  • 所以 1+2= 3 等號後面那個空白不是你打的；不想要就改用 + 串接。
"1+2=" 有引號，是字串，原樣印出；後面的 1+2 沒引號，會先算成 3。

其九・命名
補充

變數的命名規則

  • 第 1 個字元必須是英文字母或底線 _，不可以是數字。
  • 第 2 個字元之後可以是英文字母、底線或數字。
  • 大小寫視為不同：sum 和 Sum 是兩個變數。
  • 保留字不能當變數名：if、else、for、while、int、def⋯⋯
錯誤的名稱為什麼不行
3w不能用數字開頭
&my不能用特殊字元 &
Hello!不能用特殊字元 !
score-1減號會被當成減法

第十二頁
十一・轉換
補充

input() 拿回來的一定是字串

不管你輸入什麼，input() 給你的都是 字串 str
  • 所以第九頁的 h/100 才會失敗——字串不能做除法。
  • 要拿來運算，就得先轉型：整數用 int()、小數用 float()。
分成兩行寫
s = input("輸入成績")   # 拿到的是字串
s = int(s)             # 再轉成整數
合併成一行（常用）
s = int(input("輸入成績"))     # 整數
s = float(input("輸入身高"))   # 小數
只要輸入的東西要拿來運算，就一定要包一層 int() 或 float()。

第十四頁
十二・等號
補充

等號 = 不是「相等」

= 是「把右邊的值指定給左邊」
x = 1
x = x + 1      # 先算右邊 1+1，再存回 x
print(x)
2
  • 數學上 x = x + 1 不成立，程式裡卻是最常見的寫法。
  • x = x + 1 遞增、x = x - 1 遞減。
  • 可以一次指定多個：x = y = 1、m, n = 5, 6。

加分評測

某年學測數學題

賣家用 200 元成本取得模型，以成本的 5 倍作為售價，差價即為利潤。之後每次減少一半利潤來調降售價。
請問調降 3 次後售價是多少？
輸入格式（四行，依序輸入）
basic = int(input())   # 成本
a = int(input())       # 售價是成本的幾倍
b = int(input())       # 每次調降 1/b
c = int(input())       # 調降幾次

提示

  1. 依序輸入 200　5　2　3，正確答案是 300，可以拿來自我檢查。
  2. 利潤 = 售價 − 成本。每調降一次，利潤變成原來的 1/b。
  3. 輸出請印整數：print(int(answer))。

三角形判斷程式

輸入 a、b、c 三個數字，

可以 → 輸出 yes　　不可以 → 輸出 no
輸入格式（三行）

提示

  3. 輸出只要 yes 或 no，注意英文小寫，不要多印其他字。
