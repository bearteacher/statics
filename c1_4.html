全域 vs 區域：誰優先？

同名時，就近原則

int x = 100;   // 全域變數

void f() {
    int x = 5;         // 區域變數，遮蔽全域 x
    printf("%d\n", x); // 印 5（區域的）
}

int main() {
    printf("%d\n", x); // 印 100（全域的，main 裡沒有宣告 x）
    f();
    printf("%d\n", x); // 印 100（f() 沒有修改全域 x）
}

int x = 100;   // 全域變數

void f() {
    int x = 5;         // 區域變數，遮蔽全域 x
    printf("%d\n", x); // 印 5（區域的）
}

int main() {
    printf("%d\n", x); // 印 100（全域的，main 裡沒有宣告 x）
    f();
    printf("%d\n", x); // 印 100（f() 沒有修改全域 x）
}
🔖 就近原則

使用離自己最近的那個同名變數。

函式內有宣告 int x → 用函式內的區域 x 函式內沒有宣告 → 往外找，用全域 x

3 / 10

區域遮蔽 ≠ 修改全域

最重要的概念

int val = 10;   // 全域 val

void reset() {
    int val = 0;    // ← 宣告新的「區域 val」
    val = val + 5;  // 修改的是「區域 val」
    printf("%d\n", val);  // 印 5
}   // ← 函式結束，區域 val 消失；全域 val 完全沒有被碰

int val = 10;   // 全域 val

void reset() {
    int val = 0;    // ← 宣告新的「區域 val」
    val = val + 5;  // 修改的是「區域 val」
    printf("%d\n", val);  // 印 5
}   // ← 函式結束，區域 val 消失；全域 val 完全沒有被碰
🚨 核心陷阱

reset() 裡面的 val = val + 5 改的是區域 val， 全域 val 仍然是 10，沒有被修改！

很多同學誤以為：函式裡用了同名變數，就修改了全域變數。 錯！宣告新的同名變數是「遮蔽」，不是「修改」！

全域確實被修改的情況

沒有同名區域變數才會動到全域

int val = 10;   // 全域 val

void add(int x) {
    // 函式內沒有宣告 val
    val = val + x;         // 直接修改全域 val！
    printf("%d\n", val);
}

int val = 10;   // 全域 val

void add(int x) {
    // 函式內沒有宣告 val
    val = val + x;         // 直接修改全域 val！
    printf("%d\n", val);
}
✅ 區分方式
  • 函式內有宣告 int val → 使用/修改的是區域 val，全域不變
  • 函式內沒有宣告 int val → 直接使用/修改全域 val

多函式交錯追蹤

逐步追蹤全域變數

int val = 10;   // 全域

void add(int x)  { val = val + x; printf("%d ", val); }
void reset()     { int val = 0; val += 5; printf("%d ", val); }

int main() {
    add(3);    // 呼叫 1
    reset();   // 呼叫 2
    add(2);    // 呼叫 3
}

int val = 10;   // 全域

void add(int x)  { val = val + x; printf("%d ", val); }
void reset()     { int val = 0; val += 5; printf("%d ", val); }

int main() {
    add(3);    // 呼叫 1
    reset();   // 呼叫 2
    add(2);    // 呼叫 3
}
呼叫 執行內容 全域 val 印出
add(3) 全域 val = 10+3 = 13 13 13
reset() 區域 val = 0+5 = 5（全域不動） 13（不變） 5
add(2) 全域 val = 13+2 = 15 15 15

輸出：13 5 15

宣告順序：使用前 vs 宣告後

main 內的宣告順序也很重要

int a = 5, b = 3;   // 全域

int g(int a, int b) {
    a = a + b;
    b = a - b;
    return a + b;   // 驗算：g(5,7) = 5+7=12, 12-7=5, 回傳 12+5=17
}

int main() {
    int b = 7;       // 區域 b = 7（遮蔽全域 b）
    int c = g(a, b); // 此時：a = 全域5，b = 區域7 → g(5,7)
    int a = 3;       // 宣告區域 a = 3（在呼叫 g 之後！）
    printf("%d %d %d", a, b, c);
}

int a = 5, b = 3;   // 全域

int g(int a, int b) {
    a = a + b;
    b = a - b;
    return a + b;   // 驗算：g(5,7) = 5+7=12, 12-7=5, 回傳 12+5=17
}

int main() {
    int b = 7;       // 區域 b = 7（遮蔽全域 b）
    int c = g(a, b); // 此時：a = 全域5，b = 區域7 → g(5,7)
    int a = 3;       // 宣告區域 a = 3（在呼叫 g 之後！）
    printf("%d %d %d", a, b, c);
}
🚨 宣告順序陷阱

int a = 3 宣告在 g(a, b) 呼叫之後！

呼叫 g(a, b) 時，a 還沒有宣告為區域變數， 所以取的是全域 a = 5！

輸出：3 7 17

宣告順序：逐步分析

對應上一頁的完整追蹤

步驟 當前有效的 a 當前有效的 b
進入 main 全域 a=5 全域 b=3
宣告 int b = 7 全域 a=5 區域 b=7
g(a, b) 呼叫時 傳入 a=5（全域） 傳入 b=7（區域）
宣告 int a = 3 區域 a=3 區域 b=7
printf 時 a=3（區域） b=7（區域） c=17
🔖 解題技巧

建立「時間軸」：在哪個時間點，每個名稱指的是哪個變數？

本節觀念整理

✅ 四大核心規則
  1. 就近原則：優先使用最近的同名變數（區域優先於全域）
  2. 遮蔽 ≠ 修改：函式內宣告同名變數是遮蔽，全域值不變
  3. 無同名才動全域：函式內無同名區域變數時，才會直接操作全域
  4. 宣告有時間點：int a = 3 在某行之後宣告，那行之前還在用全域 a
⚠️ 多函式追蹤口訣

每次看到函式呼叫，問自己：

  1. 這個函式內有沒有宣告同名變數？
  2. 如果有 → 操作區域變數，全域不動
  3. 如果沒有 → 直接操作全域變數
