2 / 10

傳值呼叫：函式拿到的是複本

核心概念

呼叫 f(a) 時，函式收到的是 a 的一份複本。 函式內修改這個複本，完全不影響 main 裡的 a。

void addOne(int x) {
    x = x + 1;            // 修改的是複本，不是 main 的 a
    printf("%d\n", x);    // 印出複本的值
}

int main() {
    int a = 5;
    addOne(a);             // 傳入 a=5 的複本
    printf("%d\n", a);     // main 的 a 仍然是 5
}
// 輸出：6
//       5

void addOne(int x) {
    x = x + 1;            // 修改的是複本，不是 main 的 a
    printf("%d\n", x);    // 印出複本的值
}

int main() {
    int a = 5;
    addOne(a);             // 傳入 a=5 的複本
    printf("%d\n", a);     // main 的 a 仍然是 5
}
// 輸出：6
//       5
🚨 最常見錯誤

以為 addOne(a) 之後，a 變成 6。 不！傳值呼叫只傳複本，原變數永遠不受影響。

printf 的輸出時機

函式內的 printf 先於 return

int transform(int a, int b) {
    a = a * 2;             // 複本 a：3→6
    b = b + a;             // 複本 b：4+6=10
    printf("%d\n", a);     // ← 第 1 行輸出：6
    return b;              // 回傳 10
}

int main() {
    int x = 3, y = 4;
    int r = transform(x, y);
    printf("%d\n", x);     // ← 第 2 行輸出：3（x 沒有被改）
    printf("%d\n", r);     // ← 第 3 行輸出：10（函式回傳值）
}

int transform(int a, int b) {
    a = a * 2;             // 複本 a：3→6
    b = b + a;             // 複本 b：4+6=10
    printf("%d\n", a);     // ← 第 1 行輸出：6
    return b;              // 回傳 10
}

int main() {
    int x = 3, y = 4;
    int r = transform(x, y);
    printf("%d\n", x);     // ← 第 2 行輸出：3（x 沒有被改）
    printf("%d\n", r);     // ← 第 3 行輸出：10（函式回傳值）
}
🔖 輸出順序口訣
  1. 呼叫函式 → 先執行函式內所有敘述（含 printf）
  2. 函式 return → 回到 main 繼續往下執行

多函式化簡：先展開再帶值

解題核心技巧

int op3(int i, int j) { return i * j; }
int op2(int g, int h) { return g * op3(g, h); }
int op1(int e, int f) { return op2(e, f); }

int op3(int i, int j) { return i * j; }
int op2(int g, int h) { return g * op3(g, h); }
int op1(int e, int f) { return op2(e, f); }
🔖 化簡步驟
  1. 先把每個函式展開成一個等效算式
  2. 再代入數值計算
函式 等效算式 說明
op3(i,j) i * j 直接相乘
op2(g,h) g * op3(g,h) = g * g * h 展開 op3
op1(e,f) op2(e,f) = e * e * f 展開 op2

多函式化簡：計算範例

a=1, b=2, c=1, d=2

int a=1, b=2, c=1, d=2;

int a=1, b=2, c=1, d=2;
算式 展開過程 結果
op1(op2(op3(b,d),c),a) op1(op2(4,1),1) → op1(4,1) → 4*4*1 16
op2(op3(op1(d,c),a),b) op2(op3(4,1),2) → op2(4,2) → 4*4*2 32
op3(op1(op2(c,a),d),b) op3(op1(2,2),2) → op3(4,2) → 4*2 8
op3(1,op1(op2(b,c),d)) op3(1,op1(2,2)) → op3(1,4) → 1*4 4
⚠️ 由內而外

多層巢狀函式一定要從最內層開始展開，不能跳步驟。

多函式化簡：計算不同值個數

給定四種組合，問有幾種不同的值

🔖 APCS 考法

不是問每個組合的值，而是問「四個組合中，有幾種不同的數值」。

上一頁的結果：16, 32, 8, 4 → 4 種不同值（每個都不同）

如果題目設計讓其中兩個相同： 例如 op3(...)=4 且 op1(...)=4 → 只有 3 種不同值

本節觀念整理

✅ 三大核心規則
  1. 傳值 = 複本：函式內修改參數，呼叫端的原始變數完全不受影響
  2. printf 在 return 之前：函式內的輸出先發生，回到 main 再繼續
  3. 多函式由內而外：先把最內層函式展開成算式，再逐層往外計算
⚠️ 三大常見錯誤
  • 以為函式改了 x，所以 main 的 a 也變了 → 傳值不影響原變數
  • 以為 main 的 printf 先執行 → 函式內的 printf 先執行
  • 多函式組合沒有由內而外展開 → 計算錯誤
